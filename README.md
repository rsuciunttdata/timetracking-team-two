## 🛠️ Running Locally (for the best experience with the live demo)

```bash
# Clone the repo
git clone https://github.com/rsuciunttdata/timetracking-team-two.git

# Enter the project folder
cd timetracking-team-two

# Start the backend
cd back
node server.js
```

Make sure the backend is running in your terminal before opening the deployment link above! 🖤
